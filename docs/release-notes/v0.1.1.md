# mai2srt v0.1.1

精修页的拆分栏重做，另外修掉一批"中间状态"上的交互问题，以及让断句更快、更爱说话。

## 精修页拆分

- 拆分栏展开后分成两行：上面选精度，下面才是可点的字块。
- 新增「句 / 字」两档精度，**默认按句**：剪刀只出现在标点位置，不用再自己在一排字里找逗号。
- 切到按字时，**标点字块高亮成实心主题色**，句末与句中停顿一视同仁——一眼就能看到该切的地方。
- 点该行以外的任何位置都会退出当前状态；正在编辑的文字会**自动保存**，想放弃就按 Esc 或点「取消」。

## 修好的问题

- 删除待确认、或拆分栏开着时，点合并按钮会直接完成合并、丢掉那个待确认状态；现在拆分与删除互斥，中间状态下只有铅笔图标始终可点。
- 这两种状态下还能点单句试听，导致同一行上两个状态叠着；现在会锁住。
- 点其他行的空白处或时间戳区域不会退出当前状态；现在会退出（并把编辑保存下来）。
- 转录页首次打开时，状态灯与参数条可能不显示，要切到别的页面再切回来才出现；现在正常。
- 长录音的断句上下文摘要会因超长而静默失效；现在按预算裁剪，并在日志里说明。
- 在精修页拆分行时，中文标点前会多出一个空格；现在不会。

## 大模型断句

- 分批依据改成模型自身的能力上限：待断句段落多时不再切成十几轮请求（300 段由 16 次请求降到 2 次），等待时间明显缩短。
- 逐批显示进度，结束时报告有多少段由大模型给出。
- 个别段落没能对齐时会明确提示，而不是悄悄退回规则断句。
- 设置页的模型徽章同时显示上下文与最大输出；由名称推断的数值带 ≈ 前缀，服务商自己上报的不带。

## 开始转录前的检查

- 点开始前会先确认 ffmpeg、浏览器、playground 登录，以及勾选大模型断句时的大模型配置；缺哪一项就提示去哪配，不再等作业跑起来才失败。
- 只处理 .mai.json 时只检查大模型配置。

## 安装

下载下面的 `mai2srt_0.1.1_x64-setup.exe` 安装，FFmpeg 已随包内置，不需要另装 Python 或 FFmpeg。可以直接覆盖安装 0.1.0。

首次安装可能出现 Windows SmartScreen 蓝窗（安装包未签名）→ 点「更多信息」→「仍要运行」。附件中的 `SHA256SUMS.txt` 可用于校验下载是否完整。

## English

The Refine page's split bar is rebuilt, a batch of interaction problems around the inline tools is fixed, and LLM segmentation got faster and more forthcoming.

## Splitting in the Refine page

- The bar now opens as two rows: pick the granularity, then the chips below it.
- New "sentence / character" choice, **sentence by default**: scissors appear only at punctuation, so you no longer hunt for a comma among a row of characters.
- In character mode **punctuation chips are filled with the accent colour** — sentence ends and mid-sentence pauses alike — so the place you want to cut is obvious.
- Clicking anywhere outside that line leaves the current state; text being edited is **saved automatically** (press Esc or use "cancel" to discard).

## Fixed

- With a delete armed or the split panel open, clicking a merge button merged the lines and silently dropped that pending state; split and delete are now mutually exclusive, and only the pencil stays clickable in every state.
- Those two states also allowed playing a single cue, leaving two live states on one line; now locked.
- Clicking another line's blank space or timestamp area did nothing; it now leaves the current state (saving any edit).
- On the Transcribe page the status lights and the params bar could be missing until you switched pages and back; fixed.
- The LLM's whole-job context summary failed silently on long recordings; it is now trimmed to the budget and says so in the log.
- Splitting a line inserted a stray space before Chinese punctuation; fixed.

## LLM segmentation

- Batching now follows the model's own limits: many segments no longer mean a dozen round trips (300 segments: 16 requests → 2), so the wait is much shorter.
- Per-batch progress, and a closing count of how many segments the model actually produced.
- Segments the model failed to align are now reported instead of silently falling back to the rules.
- Model badges in Settings show both context and max output; values inferred from the name carry a ≈ prefix, values the provider reports do not.

## Checks before a run starts

- Starting a transcription first verifies ffmpeg, a browser, the playground sign-in, and — when LLM splitting is on — the LLM endpoint. Whatever is missing is named, instead of failing once the job is already running.
- A .mai.json run only checks the LLM endpoint.
