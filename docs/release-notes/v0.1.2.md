# mai2srt v0.1.2

针对大模型设置的思考档位做了修复：选定的档位会按各家支持的方式正确发送，模型列表也能识别出 Claude 和 Gemini 的可思考模型。另外，添加供应商时只显示该家实际支持的 API 格式。

## 思考强度档位

- 档位按各家自己的方式发送：新版 Claude 用 effort 参数，旧版 Claude 和 Gemini 2.5 用思考预算，Gemini 3 用思考档位。
- 模型不认收到的参数形式时，会自动换用它接受的形式重试；实在不支持就关闭思考继续完成断句，不会整批退回规则切分。
- 「测试」按钮按真实作业的请求方式发送：选中思考档位时，测试请求也会带上思考参数，测试通过即代表实际断句请求同样可用。
- Gemini 3 的回复上限包含思考部分，会自动留出余量，避免长回复因思考占用而截断。
- 选 off 时，Gemini 2.5 会真正关闭思考；Gemini 3 本身无法关闭思考，保持默认。

## 模型列表

- Claude（3.7 及以上）与 Gemini（2.5 及以上）会正确显示可思考图标。
- 服务商自定义的模型名（如 gemini-3-flash）不提供数值上限时，会使用内置的兜底数值。

## 添加供应商

- 每个预设只显示该家实际支持的 API 格式：DeepSeek、OpenRouter、Ollama（本地）支持 OpenAI 和 Anthropic 两种；OpenAI 官方和 Anthropic 官方各自只有一种；Gemini 支持原生和 OpenAI 兼容两种；自定义仍可选全部三种。
- 切换格式时，接口地址会自动跟随更换；手动修改过的地址不受影响。
- 使用 Ollama 的 Anthropic 格式需要 v0.14.0 及以上版本。

## 安装

下载下面的 `mai2srt_0.1.2_x64-setup.exe` 安装，FFmpeg 已随包内置。可以直接覆盖安装 0.1.0 与 0.1.1。

首次安装可能出现 Windows SmartScreen 蓝窗（安装包未签名）→ 点「更多信息」→「仍要运行」。附件中的 `SHA256SUMS.txt` 可用于校验下载是否完整。

## English

The thinking-level setting for LLM providers is fixed: the level you pick is now sent in the form each provider accepts, and the model list recognises thinking-capable Claude and Gemini models. The add-provider card also only shows the API formats a vendor really serves.

## Effort selector

- The selected level is sent the way each vendor expects: newer Claude takes the effort parameter, older Claude and Gemini 2.5 take a token budget, Gemini 3 takes a thinking level.
- When a model rejects the parameter form it receives, the splitter retries with one it accepts; if thinking is unsupported it is turned off and the job completes, without the whole batch falling back to rule-based splitting.
- The "test" button sends the same request shape as a real job: with a thinking level selected, the test request carries the thinking parameter too, so a passing test covers the real request.
- Gemini 3 counts thoughts against the reply limit; a margin is reserved so long replies are not truncated.
- "off" genuinely disables thinking on Gemini 2.5; Gemini 3 cannot turn thinking off, so the default stays.

## Model list

- Claude (3.7 and up) and Gemini (2.5 and up) now show the thinking badge.
- Gemini model names that report no numeric limits (e.g. custom aliases like gemini-3-flash) get built-in fallback values.

## Adding a provider

- Each preset only shows the formats the vendor actually serves: DeepSeek, OpenRouter and Ollama (local) offer OpenAI and Anthropic; the OpenAI and Anthropic presets offer their own single format; Gemini offers native and OpenAI-compatible; custom still offers all three.
- Switching the format retargets the endpoint URL; a hand-edited URL is left alone.
- Ollama's Anthropic format requires v0.14.0 or newer.
