# mai2srt v0.1.0

第一个公开版本：把音频或视频拖进窗口，得到词级时间戳的转录，按自己的习惯精修断句，导出标准 SRT。

## 能做什么

- 常见音频与视频格式直接拖入；超过 playground 限制（25 MiB / 约 60 分钟）的文件自动压缩、按静音分块，词级时间戳拼回完整时间轴
- 转录区分出的说话人会保留；几人挨得太近分不开时并成一条多行字幕
- 断句不满意就在精修页逐行改：拆分 / 合并 / 删除、单句试听、点行跳播、撤销重做，编辑记录随项目保存
- 断句可以让大模型帮忙挑位置（内置 DeepSeek / OpenAI / Claude / Gemini / OpenRouter / Ollama 预设，也可填任意兼容端点）；不配也能出字幕，大模型不改文字、不动时间戳
- 玫瑰（明亮）/ 余烬（暗黑）两套主题，各配液态 / 毛玻璃材质与自定义壁纸；「跟随系统」按本机时间走——19:00 之后转暗，07:00 亮回来
- 命令行 `mai2srt`（从源码安装后可用）：`transcribe` / `process` / `run`，一次一个文件，适合写进脚本；`process` 纯离线重跑断句，不消耗转录额度

## 安装

下载下面的 `mai2srt_0.1.0_x64-setup.exe` 安装即可，FFmpeg 已随包内置，不需要另装 Python 或 FFmpeg。

首次安装可能出现 Windows SmartScreen 蓝窗（安装包未签名）→ 点「更多信息」→「仍要运行」。装完第一次启动会慢一点：后端进程首次拉起，加上杀毒软件扫描新文件；之后启动很快。

## 校验

附件中的 `SHA256SUMS.txt` 可用于校验安装包下载是否完整。

## English

First public release. Drop in audio or video, get a word-level transcript, refine the segmentation the way you like it, export a standard SRT.

- Common audio and video formats drop straight in; files over the playground limits (25 MiB / ~60 min) are compressed and split on silence, and the word timestamps are stitched back into one timeline
- Speakers are kept apart; when several people talk too close together to separate, their words are folded into one multi-line subtitle
- The Refine page edits the result line by line — split / merge / delete, listen to a single cue, click a line to jump, undo and redo, with the edit record kept with the project
- Segmentation can lean on an LLM (presets for DeepSeek / OpenAI / Claude / Gemini / OpenRouter / Ollama, or any compatible endpoint) or stay rule-based; the LLM never rewrites text or timestamps
- Two themes, rose (light) and ember (dark), with liquid / frosted glass and custom wallpapers; "follow the system" runs on the clock — dark after 19:00, light again at 07:00
- A `mai2srt` CLI (from a source install): `transcribe` / `process` / `run`, one file per run, scriptable; `process` re-runs segmentation fully offline without spending transcription quota

Install with `mai2srt_0.1.0_x64-setup.exe` below — FFmpeg is bundled, no Python or FFmpeg to install. Windows SmartScreen may warn on first install (unsigned installer): "More info" → "Run anyway". The first launch takes a moment while the backend starts and antivirus scans the new files. Verify the download against `SHA256SUMS.txt`.

Transcription runs on Microsoft AI Playground's free preview service — please respect its terms of service. Written for personal study and low-frequency use; judge the risks yourself. License: GPL-3.0.
