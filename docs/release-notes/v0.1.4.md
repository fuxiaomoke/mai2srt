# mai2srt v0.1.4

本次更新修复两处影响长音频转录的问题，升级后长录音可以一次转录完成：自动分块、自动拼接，无需干预。

## 长音频转录被拒绝（HTTP 403）

- 现象：长录音（约 50 分钟左右起）转录报 HTTP 403，重试无效；更短的音频不受影响。
- 修复：自动分块的时长上限从 50 分钟降到 29 分钟。长音频切成更短的块分别转录后自动按时间戳拼接，输出不变；分块变短后每块码率也随之提高，转录质量更好。30 分钟以内的文件仍然单块直传，不受影响。

## 长视频准备阶段慢且无进度

- 现象：视频文件在切块前的静音检测会连同画面一起解码，视频越长等得越久；准备期间界面没有任何反馈，看起来像卡死。
- 修复：静音检测只解码音频流，速度大幅提升；准备过程的每一步（静音检测、切块规划、逐块编码）实时显示在任务日志与阶段指示上。

## 安装

下载下面的 `mai2srt_0.1.4_x64-setup.exe` 安装，FFmpeg 已随包内置。可以直接覆盖安装。

首次安装可能出现 Windows SmartScreen 蓝窗（安装包未签名）→ 点「更多信息」→「仍要运行」。附件中的 `SHA256SUMS.txt` 可用于校验下载是否完整。

## English

This release fixes two problems affecting long-audio transcription: after upgrading, long recordings transcribe in one go — automatic chunking, automatic stitching, no manual steps.

## Long-audio transcriptions rejected (HTTP 403)

- Symptom: long recordings (roughly 50 minutes and up) fail with HTTP 403; retries don't help. Shorter files are unaffected.
- Fix: the automatic chunking cap drops from 50 to 29 minutes. Long audio is split into shorter chunks, transcribed separately, and stitched automatically by timestamp; the output is unchanged. Shorter chunks also raise the per-chunk bitrate, improving transcription quality. Files under 30 minutes still upload as a single piece, unaffected.

## Slow, silent video preparation

- Symptom: the pre-chunking silence scan decoded the video's picture stream along with the audio, so longer videos waited minutes in the prepare stage with no UI feedback — it looked like a hang.
- Fix: the silence scan decodes the audio stream only (much faster), and every preparation step (silence scan, chunk plan, per-chunk encode) now shows in real time in the job log and stage indicator.
